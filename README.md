# Nyahururu Homes

A responsive house-rental website for Nyahururu, Kenya, built with React, Vite, Tailwind CSS, and React Router.

Property listings are loaded from a backend API.

## Run locally

Requirements: Node.js 18+ and npm.

```bash
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite.

To build for production:

```bash
npm run build
```
